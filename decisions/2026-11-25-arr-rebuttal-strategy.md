# 决策记录：ARR 论文 Rebuttal 实验与口径策略

## 1. 背景与核心问题
针对投递 ARR 的对话多模态情感识别（MERC）论文收到的三位审稿人（`mbdi` 2.5、`DFbB` 2.0、`RdNm` 2.0）意见，核心质疑集中在：同运行对齐基线公平性、门控显著性与置信区间、未校准 LLM 置信度/不确定性判别力、简单融合基线与去混杂消融对比、以及小参数规模 LLM 泛化性。需要在 Rebuttal 窗口期（5,000 字符纯文本限制内）确定是否补跑新模型 API 实验及数据呈现口径。

## 2. 备选方案对比

| 方案 | 优点 | 缺点 / 风险 |
| :--- | :--- | :--- |
| **方案 A：零新增 API 成本 + 全量已有缓存深度统计挖掘（选定）** | 零重跑风险与时间成本；直接从已有 12 组预测与 50,796 条测试缓存中提取配对 Bootstrap CI、McNemar/Mann-Whitney 检验、AUROC、4,095 组同等调参投票对比、去混杂 3 视图重搜消融及 `KEEP/CHANGE` 对比，主表数字 100% 严丝合缝；聚焦最强正向证据。 | 未实测 7B/8B 开源小模型（通过跨档次模型跨度与门控下界设计进行理论与实证结合回应）。 |
| **方案 B：额外调用 API 补跑 7B/8B 小模型及说话人标签 Prompt 消融** | 对小模型泛化问题有直接实验数字。 | 增加时间与调参开销，且可能引入新实验波动或触及 ARR 仅允许轻量补充实验的边界。 |

## 3. 最终决定与理由
- **最终选择**：**方案 A（基于已有 DeepSeek + Qwen 全量 12 组缓存做只读深度统计增强，聚焦强支撑结果，小模型采用跨档次跨度+下界保障机制论证）**。
- **核心理由**：现有缓存挖掘出的全量 12 组统计结果（24/24 视图 AUROC $p < 2\times 10^{-16}$、12/12 击败同等调参离散投票与口头 `KEEP/CHANGE`、同运行 `Full (aligned)` 严格净提升）已经极具说服力，且与已提交论文表格完全一致，不主动暴露任何自摆乌龙的内部重放差异，便于发导师审阅把关。

## 4. 预期结果与评判标准（供 `2026-12-15` 回看）
