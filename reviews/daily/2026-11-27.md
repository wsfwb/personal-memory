# 2026-11-27 日常记录

## 今日推进的事
- 在本机把 skill 自进化框架（develop → lint → snapshot → selftest → evaluate）跑通，替换了只能在开发机上运行的三个依赖（沙箱、测试环境 runner、技能中心上传），框架代码本身不改。
- 完成「只换 develop agent」的对照实验：5 个 agent（含 1 个通用 agent）、同模型、共享基线，第 1 轮全部跑完或记录失败原因，每个完成的版本复测 2–3 次。
- 给 skill 自进化框架加了产品用的网页（`autodev web`）：填需求文档 + 测试集建任务、一键开始/停止循环、看每一轮 7 步进度和每条用例的自测/核验结果、版本 zip 下载、加人工反馈。标准库 http.server + 原生 JS，不引入前端依赖；新增 5 个接口测试，全量 75 个测试通过。

## 今日思考 / 收获
- 同模型下 agent 的差别主要在效率和稳定性，不在改动方向；单轮质量差距可以靠多一轮追平。
- 评测噪声（单次约 8 分）比 agent 之间的质量差还大，比较之前先测噪声。
- 详见学习笔记：[Skill Loop 中只换 develop agent 的实测](../../learning/topics/skill-loop-develop-agent-benchmark.md)
- 给 CLI 工具加网页的省力做法：网页层只做「薄壳」——建任务直接调 CLI 的函数复用全部校验，跑循环起 CLI 子进程（自己的会话，关网页不影响），进度直接读流水线已经落盘的 state.json / run.json / result.json，不另建状态存储；停止 = 发 SIGTERM 等同 Ctrl-C，断点续跑天然成立。见决策记录：[Web 层复用 CLI 的薄壳架构](../../decisions/2026-11-27-skill-autodev-web-thin-shell.md)
