# 学术论文 Rebuttal 审校防反驳清单

## 核心原则：绝不编造超出原文 Prompt / 公式的事后动机
审稿人（尤其是高置信度审稿人）通常会逐字对照附录 Prompt、Schema 与主表数字，Rebuttal 中任何与原文微小不一致的“事后解释”都极易成为反驳靶子：

1. **Prompt 与 Schema 严格对齐**：
   - 若历史对话已包含 `<SPEAKER>: <TRANSCRIPT>`，不要将目标句漏标解释为“防止角色先验偏见”，直接坦诚说明模板设计如此、承认在双人连续轮次可能产生延续模糊，并用分层实测数据证明多模态主干与门控兜住了下限。
   - 若 Schema 对某字段（如 `uncertainty`）仅定义数值范围 `[0,1]` 而未写主观语义，不要过度诠释为特定物理含义，直接用实证分布（如 $c+u \neq 1$ 占比、AUROC 接近度）支撑公式设计。
2. **指标名称与共享行口径前后一致**：
   - 区分 `W-F1` 与 `accuracy`，绝不混用术语；
   - 若正文声明某基线行（如 `Context`）跨骨干共享，则新增模型实验与统计指标（如 AUROC）也必须统一报单一共享值而非骨干区间。
3. **跨工作对比必须核实原论文 PDF 主表数字**：
   - 只列方法名宣称超越而无具体数字难以说服审稿人上调分数；必须逐篇核对原论文同数据集、同指标（如 MELD / IEMOCAP W-F1）精确数值，若有个别单点持平或互有胜负需坦诚点明模型档次。
4. **跨审稿人回复内部逻辑自洽**：
   - 若某审稿人已指出“固定阈值消融存在尺度混杂”，则在给其他审稿人论证模块贡献时也应同步升级为“重调参无混杂消融”结果，防止 AC 交叉阅读时发现口径漏洞。
