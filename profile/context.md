# 个人背景与现实上下文（Context）

> 说明：本文件供本地 Agent 了解你的基本情况、能力边界与现实约束，避免给出脱离实际的建议。随着你的成长，让 Agent 持续更新此文件。

## 1. 当前身份与主线方向
- **当前角色 / 阶段**：后端与 AI Agent 方向工程师；目前处于**切入期 / 蓄力期（尚未接触团队核心项目）**。
- **核心关注领域**：
  - **AI Agent 工程化**：Agent 架构设计、上下文/记忆管理（Context & Memory Engineering）、工具调用（Tool/Skill 机制）、稳定性与评测（Eval）。
  - **后端研发**：服务架构、高可用与工程规范、底层基础设施理解。
  - **职业破局**：如何通过高质量完成外围/基础任务建立工程信任，尽快摸清核心链路并切入核心项目。

## 2. 技能栈与优势
- **主攻方向**：后端开发 + AI Agent 应用研发
- **正在提升**：
  - 深度掌握生产级 Agent 系统的架构模式与痛点解法；
  - 提升后端复杂系统设计与问题排查深度；
  - 熟悉所在团队现有核心业务架构与技术债痛点，寻找切入抓手。

## 3. 时间与精力约束（决策时的重要边界）
- **阶段特点**：由于暂未背负最核心项目的重度排期压力，一方面要**把当前手头的非核心/外围任务做到超出预期的靠谱（建立信任筹码）**，另一方面正好有窗口期主动阅读核心仓库源码、沉淀通用工具/Skill 或补齐底层短板。
- **常见风险 / 需警惕的消耗**：
  - 因暂时没接触核心业务而产生迷茫、焦虑，导致业余时间在零散热点上盲目发散；
  - 轻视手头的外围小需求，错失证明工程靠谱度的机会。

- 希望 Agent 保持**直接、理性、客观**，在我偏离主线或过度纠结时直接提醒。
