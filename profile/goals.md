# 阶段目标与优先级（Goals & Non-Goals）

> 说明：当你不确定该不该做某件事时，这是第一道过滤器——**不能推进核心目标、也不属于必要生活保障的事，默认不做或延后。**

## 1. 长期愿景（1~3 年）
- 成为**既懂扎实后端工程架构、又能落地高可靠生产级 AI Agent 系统**的核心工程师，拥有可复用的技术方法论与代表作项目。

## 2. 当前季度核心目标（最多不超过 3 个）
1. **[目标 1 - 职场破局：切入核心链路]**：
   - 高标准交付当前手头的每一项任务，建立“交付稳、响应快、有闭环”的信任度；
   - 主动摸清团队核心项目的代码架构、上下游链路与痛点（如日志排查、评测、文档缺失、开发提效工具），寻找切入机会。
2. **[目标 2 - 硬核积累：Agent + 后端体系化沉淀]**：
   - 每遇到一个后端或 Agent 相关的真实问题/源码设计，不再停留在“跑通就行”，而是提炼原理与最佳实践沉淀到 `learning/`；
   - 围绕 Agent 记忆、上下文工程、多工具编排与后端高可用，打造自己的实战理解与实验代码。
3. **[目标 3 - 认知复利：跑通个人记忆与决策系统]**：
   - 坚持把日常工作踩坑、阅读核心代码的心得、以及关键选择记录进 `personal-memory`，每周复盘校准方向。

## 3. 当前「不做清单」（Anti-Goals / Non-Goals）
- 不在还没吃透主线（后端基本功 + Agent 核心机制 + 团队核心架构）前，盲目追逐每天冒出来的碎片化 AI 噱头工具。
- 不在未验证核心需求前陷入工具链/界面的过度折腾。
- 不做“只收藏不消化、只计划不复盘”的虚假努力。
